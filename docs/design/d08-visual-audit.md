## System and motion decisions

Single4/8/12/16/24/32/48 spacing rhythm; one control radius, stronger section headings and consistent technical12px metadata. Body/source14–15px with generous line height; dense inspector data remains selectable/wrapped. At768px use mobile navigation to recover working width;1024 retains compact sidebar. Avoid blur, ornamental photos, new UI framework and remote assets.

Motion reflects a completed data/state transition only. Ordinary entrances target240–380ms total, first8 cards at most, using opacity/transform. Embedding reveals a single inspector/window, not384 simultaneous tweens. Manifest feedback never animates a fabricated progress value; native progress comes from the backend. Shared scoped context must revert on replacement, StrictMode cleanup, unmount/tab/route/cancel, hidden tab and reduced-motion change. Simulator reducer remains unchanged. Hover uses CSS140–180ms; no infinite timelines or scroll-driven reveal.
