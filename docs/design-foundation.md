## Application and explicit limits

Applied written guidance: one spacing/radius/type/color system, readable hierarchy, aligned content edges, restrained accents, real product UI, source-based copy, no invented metrics, visible focus, skip link, labeled menu, and reduced motion. Manrope is the UI face; IBM Plex Mono identifies technical metadata. Fonts are served locally. Navy surfaces with cyan/mint emphasis follow the project brief; secondary blue/periwinkle icon tones distinguish learning stages.

This is **source-guided adaptation, not a full Taste toolkit build or Taste gate PASS**. The current skill targets company/marketing sites and prescribes full-screen hero sections, randomized palette/layout dealers, award-site moments, and kit-only browser checks. The project explicitly requests a functional React developer-tool shell, five lab routes, honest PLANNED labels, and independent browser tests; these requirements take precedence. We therefore did not install/copy its asset kit or run its installer, dealers, checker, or gate. D01 uses its own Playwright/axe checks and actual screenshots; no upstream checker result is claimed.

GSAP Skills/runtime are **NOT USED in D01**; no GSAP performance/lifecycle result is claimed. Main animation work is D07/D08. CSS hover/press responses are short and rest under `prefers-reduced-motion`. Interface diagrams in D01 are clearly labeled planned learning paths, not running pipelines.
